# Fictional master's thesis: Swiss periodicals, 1830–1960

> [!WARNING]
> This repository is a **teaching example** for the workshop "GitHub as a Project Management Tool" (University of Bern, HS2026).
> The thesis, the people, and the dates are **fictional**. The data are **synthetic**. Do not cite this repository as research.

## About

This repository plans, documents, and shares a fictional MA thesis in Digital Humanities (Major).
The thesis asks how the landscape of Swiss periodicals changed between 1830 and 1960 by language, place, and subject.

| Item                   | Value                                                  |
| ---------------------- | ------------------------------------------------------ |
| Data                   | `data/clean/synthetic-periodicals.csv`, 30 synthetic records |
| Plan                   | GitHub Issues, milestones, and one GitHub Project      |
| Fictional registration | 2026-12-01                                             |
| Fictional submission   | 2027-06-01                                             |
